WINDOW USE / 경로 미리보기

점 네 개로, 서로 다른 선.

번호가 붙은 점을 움직여 보세요. 같은 좌표가 ‘통과할 점’인지 ‘곡선을 당기는 손잡이’인지에 따라 모양이 달라집니다.

입력 4개 좌표초록 경로 —좌표계 800 × 500
드래그 또는 좌표 입력 · 점 선택 후 방향키로 1, Shift+방향키로 10 이동
재생은 각 선의 길이에 비례해 좌표를 배분한 약 3초 이동입니다. 실제 OS 입력은 발생하지 않습니다.

같은 점, 다른 해석

1 → 2 → 3 → 4를 모두 통과합니다. α = 0.5. 경유점을 지정하는 기본 방식으로 추천합니다.

모든 점을 직선으로 연결합니다. 모서리를 그대로 유지합니다.

1에서 시작해 4에서 끝납니다. 2·3은 조절 손잡이이며, 보통 그 점을 통과하지 않습니다.

X / Y · 미리보기 내부 좌표




부드러움이 장애물 회피를 보장하지는 않습니다. ‘위로 돌아가는 경로’에서 점을 옮겨 곡선이 꺾은선 바깥으로 부푸는 부분을 확인해 보세요. 실제 회피 기능에는 금지 영역과 대상 크기를 고려한 별도 검사가 필요합니다.


이 HTML은 곡선 모양을 비교하는 독립 데모입니다. Window use의 드래그 기능은 변경하지 않습니다. Catmull–Rom 양 끝의 접선은 바깥쪽 점을 반사해 계산하며, 연속 중복점은 하나로 합칩니다. 화면 표시와 등거리 이동은 수치 근사입니다.
