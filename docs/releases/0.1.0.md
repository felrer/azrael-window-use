# Azrael Window Use 0.1.0

2026-11-16 · Windows x64 · 로컬 대화형 데스크톱 · 무서명 포터블 배포

## 설치

[v0.1.0 릴리스](https://github.com/felrer/azrael-window-use/releases/tag/v0.1.0)의 `WindowUseMCP-0.1.0-win32-x64.zip`을 전부 해제합니다. `WindowUseMCP.exe`는 설정창을 열며, MCP 클라이언트에서는 `--mcp` 인수로 실행합니다. Azrael·VS Code·별도 Node.js 설치는 필요하지 않습니다. 연결 예시는 [README](../../README.md)에 있습니다.

## 포함 기능

- 창 캡처, 선택적 UIA 정보, UIA 요소 조작
- 가상화 마우스 입력, 직선·구심 Catmull–Rom 드래그, 클릭·텍스트·키 묶음
- 사용자 키보드 보관과 포커스 복원, 억제 중 Esc 중단과 최대 10초 안전장치
- 앱별 승인, 보호 앱 마스킹, 공용 중지·설정과 연결별 임시 권한
- 여러 MCP 클라이언트가 서비스와 트레이 하나를 공유
- 최신 호환 설치본을 실행하면 진행 중 요청과 입력 정리 후 서비스 전환

Azrael 채팅 승인 연동은 새 공용 서비스 어댑터를 포함한 Azrael 빌드에서 사용할 수 있습니다. 기존 Azrael을 자동 업데이트하지는 않습니다. 인터넷 자동 다운로드도 제공하지 않습니다.

## 검증

검증 환경은 현재 Windows x64 개발 데스크톱입니다. 모든 아래 실행은 종료 코드 0입니다.

- 소스 테스트 47개 통과. 이후 ASAR 물리 파일 접근 수정에 해당하는 공용 서비스 테스트 6개를 다시 실행해 통과했습니다.
- Rust/MSVC·CMake 빌드와 Raw Input, 키보드 예약, 억제 복구, 묶음, 곡선, 자율 초기화, 커서 보호 자체 검사 통과.
- 패키징: ASAR 전체 내용, 네이티브 매니페스트, ZIP 전체 파일 해시와 입력 불변성 검증 통과.
- 실제 배포 실행 파일: 표준 SDK stdio 연결, 25개 도구 검색, 두 연결의 동일 서비스 재사용, 창 조회·UIA 관찰, 승인 거부·승인 후 텍스트 입력, 보호 UI 마스킹, 가상화 마우스 클릭의 실제 반영, 공용 Stop·재개, 연결별 종료 검증 통과.

초기 패키지의 ASAR 해시 접근 오류를 수정한 뒤 다시 빌드했습니다. 마스킹 검증은 창 전환 직후의 `state_changed` 거절에 대해 읽기 전용 캡처를 재조회했습니다. 입력 결과가 불확실한 조작은 재실행하지 않았습니다.

## 미검증 범위와 제한

깨끗한 별도 PC, 개별 타사 MCP 클라이언트, 설치된 Azrael 채팅 UI 및 실제 물리 입력 중 버전 전환은 이번 배포 검증에 포함하지 않았습니다. Linux·macOS·ARM64·헤드리스·UAC 보안 데스크톱은 이 배포의 지원 대상이 아닙니다. 실제 사용자 동시 입력·IME·재매핑 드라이버 호환성에는 별도 실기 검증이 필요합니다. Windows는 무서명 앱에 게시자 확인 알림을 표시할 수 있습니다.
